## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_conditions.Main
java -cp build part2_activity.Main
java -cp build part3_recommender.Main
```

## Что показать на защите

Запусти демонстрацию условий, затем возрастные категории и рекомендации для двух разных сочетаний возраста и жанра. Покажи flowchart.svg.

## Как объяснить

if выбирает ветвь по boolean-условию; else обрабатывает альтернативу. && требует истинности двух условий, || — хотя бы одного, ! меняет значение. String.equals сравнивает содержимое строк. Рекомендация зависит одновременно от возраста и жанра.

## Возможные вопросы

- **Почему не сравнивать строки через ==?** == сравнивает ссылки, equals — текст.
- **Зачем порядок условий возраста?** Чтобы более общая ветвь не перехватила частный случай.
- **Что происходит в 6 и 23 года?** В исходном условии есть пробелы: эти возраста не покрыты. Программа явно просит уточнить деятельность, а не скрывает допущение.
